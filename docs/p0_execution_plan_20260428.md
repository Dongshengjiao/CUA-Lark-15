# CUA-Lark P0 Execution Plan

版本：`v1.0`

日期：`2026-04-28`

目标截止：`2026-05-07`

## 1. P0 产品定义

P0 不是一个万能 Agent，也不是一个测试平台全集。

P0 的唯一目标是做出一个**普通飞书用户看得懂、愿意用、现场能稳定演示**的产品最小闭环：

**用户输入一句话任务 -> CUA-Lark 在飞书桌面端执行 -> 用户看到过程 -> 用户拿到结果与证据**

P0 产品名建议：

**CUA-Lark：飞书会议协作副驾**

P0 口号建议：

**一句话，把飞书里的协作任务交给 AI。**

## 2. P0 核心场景

P0 只做 3 个任务，不再扩散：

### 场景 1：帮我约

用户输入：

`帮我在飞书里创建一个明天下午 2 点的项目例会，并写上“讨论 Demo 分工”`

系统完成：

1. 打开 `Calendar`
2. 创建日程
3. 填写标题、时间、描述
4. 可选填写参与人草稿
5. 返回执行结果和截图证据

这是主场景，也是第一优先级。

### 场景 2：帮我发

用户输入：

`帮我在当前群里发一句“今晚 8 点准时开会”`

系统完成：

1. 打开 `IM`
2. 聚焦会话输入框
3. 输入消息
4. 发送
5. 返回执行结果和截图证据

这是第二优先级，适合现场 Demo。

### 场景 3：帮我记

用户输入：

`帮我新建一份文档，标题叫“比赛答辩提纲”，并写一个三段式草稿`

系统完成：

1. 打开 `Docs`
2. 新建文档
3. 填写标题
4. 填写正文草稿
5. 返回执行结果和截图证据

这是第三优先级，用来补齐 `IM + Calendar + Docs` 三产品覆盖。

## 3. P0 页面信息架构

P0 只做 3 个页面。

### 页面 A：Agent Console

目标：

1. 让用户发起任务
2. 让用户理解这个产品能干什么

页面元素：

1. 标题：`CUA-Lark`
2. 副标题：`让 AI 像你一样使用飞书`
3. 自然语言输入框
4. 三张推荐任务卡：
   - `帮我约`
   - `帮我发`
   - `帮我记`
5. 最近一次运行记录

### 页面 B：Running View

目标：

1. 让用户知道 AI 正在干嘛
2. 让评委看到这不是“黑盒”

页面元素：

1. 当前任务名
2. 当前产品域：`IM / Calendar / Docs`
3. 当前步骤
4. 已耗时
5. 当前截图缩略图
6. 异常提示

### 页面 C：Result View

目标：

1. 让用户看到结果
2. 让评委看到证据

页面元素：

1. 成功 / 失败状态
2. 完成了什么
3. 最终截图
4. 步骤轨迹
5. 报告入口
6. 重试按钮

## 5. P0 验收标准

到 `2026-05-07`，只要同时满足下面 5 条，就算 P0 完成：

1. 用户可以**不通过命令行**发起任务
2. `帮我约` 真实可演示
3. `帮我发` 真实可演示
4. 至少 `2` 条真实任务能稳定跑通
5. 每次执行后都能展示结果、截图和步骤证据

补充目标：

1. `帮我记` 如能稳定跑通，产品完整度会明显提高
2. 如果三条都通，比赛表达会非常顺

## 6. 团队角色分工

团队共 3 人，分工不平均，而是按系统与强项切。

### 成员 A：计算机背景，macOS 主开发

角色：

**桌面执行负责人**

负责：

1. `macOS` 真机执行链路
2. 飞书桌面端真实联调
3. `Calendar / IM / Docs` 主链稳定性
4. 异常恢复
5. Demo 机器最终联调

不负责：

1. 控制台前端主开发
2. 答辩主叙事

### 成员 B：计算机背景，Windows，需要虚拟机

角色：

**控制台前端 / 报告展示负责人**

负责：

1. `Task Console` 前端页面
2. 运行状态页
3. 结果页
4. 报告展示
5. benchmark summary 展示

不负责：

1. macOS 真机执行主链
2. 飞书权限和窗口校准

### 成员 C：AI PM 背景，有开发能力

角色：

**产品 Owner + 技术统筹 + 任务编排负责人**

负责：

1. PRD、范围控制、任务模板
2. 答辩主线与 PPT
3. 自然语言任务编排
4. 验证策略与产品文案
5. 跨成员集成
6. 必要时代码补位

不负责：

1. 成为唯一前端实现者
2. 深陷 macOS 点位调试

## 9. 当前最优策略

如果资源有限，不要追求“三条全都做到满分”，而是：

1. 把 `帮我约` 做成最强主场景
2. 把 `帮我发` 做成第二展示场景
3. 把 `帮我记` 做成完整度补充

也就是说：

1. `Calendar` 是主线
2. `IM` 是增强线
3. `Docs` 是补全线
