## [20:00] Pattern: imperative step-by-step prompts for generic VLM CUA agents

**Type**: optimization
**Tags**: `architecture`

通用 VLM（qwen3-vl-plus）做 CUA 的 prompting 风格规则：

1. **任务不写意图，写动作序列**：把 task 拆成"Step 1: Use action_X with param_Y. Step 2: ..."
2. **显式 action 名 + 显式参数名**：actor 看不到 action schema 的 docstring，要在 task 里告诉它 `multi_Hotkey` 而不是 `Hotkey`、`open_app` 而不是说"打开"
3. **AppleScript 优先于 GUI 操作**：能 `run_apple_script` 完成的事不用 hotkey/click
4. **`input_text` 优于多次 hotkey**：一次性塞完整字符串
5. **`max_actions_per_step: 1` + 适度 `max_steps`**：单步可调试，失败自动 retry
6. **Brain 会自动跳步**：task 写完整链路即可，模型截图发现某一步已达成时会自己跳过

**Before**: "open Calculator" / "send hello to 钟梓文" → 失败、幻觉、循环重试
**After**: 显式 action + 参数化 step-by-step → 2-3 步走通，<1 分钟

**Status**: ✅ verified
